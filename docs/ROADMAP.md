# Online Tech Uganda Ltd — Product Roadmap

> One brand, one integrated system: **online computer store + digital agency + software company + online learning platform + IT services**.

**Brand colors:** Primary `#F15A29` (orange) · Secondary `#282363` (indigo)
**Stack:** Next.js (frontend) · FastAPI/Python (backend) · PostgreSQL (database) · Resend (email)
**Hosting:** Frontend → Vercel · Backend → VPS · Architecture → monorepo (pnpm + Turborepo)

---

## Vision

| Pillar | What it becomes |
| --- | --- |
| 🖥️ Shop | An online computer & accessories store |
| 🌐 Services | A digital agency (websites, mobile apps, systems) |
| 📱 Software | A software products company (School/POS/Inventory/SACCO) |
| 🎓 Learn | An online learning platform with courses & certificates |
| 🔧 Support | An IT services, repairs & networking company |

---

## Phases

### Phase 1 — Startup (Months 1–2) · _foundation in this repo_
Launch the company and start generating income quickly.
- Logo, business profile, Website v1, social pages.
- Sections: **Home, Shop, Services, Learn, About, Contact**.
- Offer: laptops, accessories, website design.
- 🎯 Revenue goal: **1–3M UGX/month**.

### Phase 2 — E-commerce Growth (Months 3–6)
Turn the site into an active online store.
- Product catalog, shopping cart, order system, delivery management, customer accounts.
- Partners: suppliers, riders.
- 🎯 **4–8M UGX/month**.

### Phase 3 — Professional Services (Months 6–12)
- Website dev, mobile app dev, software systems, repairs & support intake.
- 🎯 **5–15M UGX/month**.

### Phase 4 — Online Learning Platform (Year 1)
- Courses: Computer Basics, MS Office, Web Dev, Programming, Networking.
- Flow: Register → Pay → Unlock videos → Learn → Certificate.
- Pricing: 20k–100k UGX/course; subscription 20k UGX/month.

### Phase 5 — Software Products (Year 1–2)
- School Management, Inventory, POS, SACCO systems.
- Revenue: setup fees + annual subscriptions.

### Phase 6 — Company Mobile App (Year 2)
- Shop, courses, service requests, repair booking, support.

### Phase 7 — Marketplace Expansion (Year 2–3)
- Suppliers list products. Revenue: commission, featured listings, ads.

---

## Priority order
- **Months 1–3:** Website · computer sales · accessories
- **Months 4–6:** Website-development services · repair services
- **Months 7–12:** Online learning platform · mobile apps & systems
- **Year 2+:** Marketplace · company mobile app · regional expansion

Computer sales (margin) · Accessories (margin) · Website dev (project fees) ·
Mobile apps (project fees) · Software systems (setup + subscriptions) ·
Online courses (recurring) · Repairs (service charges) · Marketplace (commissions).
